# Makhara Invoice

მარტივი მრავალმომხმარებლიანი ინვოისების სისტემა `invoice.makhara.ge`-სთვის.

## ფუნქციები

- ადმინისტრატორისა და მომხმარებლის როლები;
- მომხმარებლების მონაცემების სრული გამიჯვნა;
- თითო მომხმარებელზე რამდენიმე გამცემის პროფილი;
- კომპანია, ინდ. მეწარმე და ფიზიკური პირი;
- შენახული მიმღებების ბაზა;
- ქართული, ინგლისური და რუსული ინვოისები;
- დღგ-ის პირობითი ჩვენება და 18%-ის ავტომატური გამოთვლა;
- ფასის შეყვანა დღგ-ის ჩათვლით ან მის გარეშე;
- GEL, USD და EUR;
- კლასიკური და თანამედროვე A4 Portrait დიზაინები;
- კომპაქტური A4 Landscape დიზაინი ბევრი პოზიციისთვის;
- დაბალანსებული მრავალგვერდიანი PDF განმეორებადი სათაურებითა და გვერდის ნომრებით;
- თანამედროვე ადაპტიური ინტერფეისი Desktop და Mobile ეკრანებისთვის;
- სრულფასოვანი Light/Dark Mode მომხმარებლის არჩევანის დამახსოვრებით;
- PDF-ის ერთღილაკიანი ჩამოტვირთვა და ბეჭდვა;
- ინვოისის დუბლირება, რედაქტირება და Soft Delete;
- თითოეული გამცემის დამოუკიდებელი წლიური ნუმერაცია;
- ინვოისის მომენტისთვის გამცემისა და მიმღების მონაცემების Snapshot.

## მოთხოვნები

- PHP 8.2 ან ახალი;
- MySQL 8+ ან თავსებადი MariaDB;
- PHP გაფართოებები: `pdo_mysql`, `mbstring`, `json`;
- Apache `mod_rewrite`;
- HTTPS.

## დაყენება

სრული ინსტრუქცია იხილეთ [docs/INSTALLATION_GE.md](docs/INSTALLATION_GE.md)-ში.

მოკლედ:

1. ატვირთეთ პროექტი სერვერზე.
2. დომენის Document Root მიუთითეთ პროექტის `public` საქაღალდეზე.
3. შექმენით ცარიელი MySQL მონაცემთა ბაზა და მომხმარებელი.
4. გახსენით `https://invoice.makhara.ge/install.php`.
5. შეავსეთ მონაცემები და დაასრულეთ ინსტალაცია.
6. ინსტალაციის შემდეგ წაშალეთ `public/install.php`.

## მნიშვნელოვანი

ეს სისტემა ქმნის კომერციულ ინვოისს PDF ფორმატში. ის არ ანაცვლებს `RS.ge`-ს ოფიციალურ საგადასახადო ანგარიშ-ფაქტურას, როცა ასეთი დოკუმენტი კანონით საჭიროა.

ელფოსტით გაგზავნა, ლოგო, ხელმოწერა და ბეჭედი საწყის ვერსიაში შეგნებულად არ შედის.
