# ცვლილებების ისტორია

## 1.2.5

უსაფრთხოებისა და სიზუსტის განახლება.

- **ნუმერაცია:** ინვოისის ნომერი ახლა არსებული ინვოისებიდან გამოითვლება (გამცემი + პრეფიქსი + წელი). უკანა თარიღით ინვოისი აღარ არღვევს მიმდინარე წლის ნუმერაციას და აღარ ბლოკავს ახალი ინვოისების შექმნას. უკვე დაზიანებული გამცემები ავტომატურად გასწორდება. შენიშვნა: პრეფიქსის შეცვლისას ახალი პრეფიქსის ნუმერაცია `0001`-დან იწყება;
- **ინსტალერი:** უარს ამბობს მუშაობაზე, თუ ბაზაში უკვე არსებობს მომხმარებლები (დაცვა `storage/config.php`-ის დაკარგვის შემთხვევისთვის);
- **თანხები:** გამოთვლა მთელი რიცხვებით (თეთრებში) ხდება. ინვოისის შეჯამება (ქვეჯამი − ფასდაკლება + დღგ = სულ) ყოველთვის ზუსტად ემთხვევა; ბრაუზერში ცოცხალი ჯამი იგივე ალგორითმს იყენებს. ზედმეტად დიდი რაოდენობა/ფასი უარყოფილია;
- **გაცემული ინვოისი საბოლოოა:** მისი რედაქტირება, მონახაზად დაბრუნება და წაშლა აღარ შეიძლება; შესაძლებელია ნახვა, ბეჭდვა, PDF და ასლის შექმნა. ღილაკი „შენახვა და გახსნა“ გადაერქვა „ინვოისის გაცემა“ და დადასტურებას ითხოვს;
- **პროფილი:** პაროლის ან ელფოსტის შესაცვლელად მიმდინარე პაროლია საჭირო (მცდელობების ლიმიტით). პაროლის შეცვლისას სხვა მოწყობილობებზე გახსნილი სესიები იხურება; ლოგინისას განახლდება CSRF ტოკენი;
- დაემატა `tests/integration.php` (მონაცემთა ბაზის ტესტები) და გაფართოვდა `tests/run.php`.

## 1.2.4

- ცხრილების სათაურის ზედა მარცხენა და მარჯვენა კუთხეები card-ის მომრგვალებას ზუსტად მიჰყვება;
- ცხრილის ფონი და საზღვრები card-ის გარეთ აღარ გამოდის;

## 1.2.3

- ინვოისის ფორმაზე მთლიანი გვერდის ჰორიზონტალური სქროლი სრულად მოიხსნა;
- გამოსწორდა დამალული დიზაინის radio input-ების ზედმეტი სიგანე;
- პროდუქტების ფართო ცხრილს მცირე ეკრანებზე მხოლოდ საკუთარი შიდა სქროლი აქვს და გვერდის განლაგებას აღარ აფართოებს.

## 1.2.2

- მობილურ ეკრანზე ცხრილების ხელოვნური მინიმალური სიგანე მოიხსნა;
- ინვოისების, მიმღებებისა და მომხმარებლების ცხრილები მობილურზე ადვილად წასაკითხ card/list ხედში გადადის;
- გამოსწორდა ცხრილების მარჯვნივ გადაცდენა და კონტენტის მოჭრა;
- Light/Dark Mode ახლა მყისიერად იცვლება, შუალედური თეთრი-მუქი ფერებისა და დაყოვნების გარეშე.

- განახლდა გვერდითი მენიუ, ზედა პანელი, Dashboard, სტატისტიკური ბარათები და მობილური ნავიგაცია;
- ცხრილები, ფილტრები, ფორმები, ღილაკები, სტატუსები და ცარიელი გვერდები უფრო მკაფიო და ადვილად გამოსაყენებელი გახდა;
