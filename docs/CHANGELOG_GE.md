# ცვლილებების ისტორია

## 1.2.7

- **ძებნა გასწორდა:** ინვოისების, მიმღებებისა და მომხმარებლების სიაში საძიებო ველი შეცდომას აბრუნებდა (SQL პარამეტრის განმეორების გამო). ახლა სამივე ძებნა მუშაობს;
- **შეცდომების დამუშავება:** დაუმუშავებელი შეცდომა და fatal error ჩაიწერება `storage/logs/app-თარიღი.log`-ში, მომხმარებელი კი ხედავს გასაგებ 500 გვერდს შეცდომის კოდით (ტექნიკური დეტალების გარეშე);
- **უსაფრთხოების ჰედერები:** Content-Security-Policy (nonce-ით), HSTS (HTTPS-ზე) და გამკაცრებული `.htaccess` ფაილები (`storage`, პროექტის ფესვი, `.user.ini`). სესიის Secure cookie ახლა `app.url`-ითაც განისაზღვრება და პროქსის უკანაც მუშაობს;
- **შესვლის დაცვა:** დაემატა IP-ზე ლიმიტი (30 წარუმატებელი მცდელობა / 15 წუთი), `login_attempts`-ის ავტომატური გასუფთავება, ელფოსტის არსებობის დადგენა დროით აღარ შეიძლება, ჰეში საჭიროებისას ახლდება. პროქსის უკან მუშაობისას `storage/config.php`-ში მიუთითეთ `trusted_proxies` (იხ. `docs/INSTALLATION_GE.md`);
- **პაროლის წესი:** მინიმუმ 8 სიმბოლო, გავრცელებული პაროლების აკრძალვა, მარტივი მიმდევრობების/გამეორებების და ელფოსტის ან სახელის შემცველი პაროლების აკრძალვა. ვრცელდება პროფილზე, მომხმარებლების ფორმაზე და ინსტალერზე;
- **სესიის ვადა:** უმოქმედობის გამო სესია იხურება (`session_idle_minutes`, ნაგულისხმევად 120 წუთი; 0 = გამორთულია);
- SQL მოთხოვნები ახლა მუშაობს MySQL-ის `ANSI_QUOTES` რეჟიმშიც; ტესტები ამ რეჟიმში სრულდება;
- დაემატა `tools/cloudflare-trusted-proxies.php`: Cloudflare-ის ოფიციალური IP სიიდან ამზადებს `trusted_proxies` ბლოკს; დოკუმენტაციაში დაემატა Cloudflare-ის პარამეტრების რეკომენდაციები.

## 1.2.6

- **მონახაზის რედაქტირება:** თუ მონახაზში გამცემი ან ინვოისის თარიღის წელი იცვლება, ინვოისი ახალი გამცემის/წლის შემდეგ თავისუფალ ნომერს იღებს. აქამდე ის ძველ ნომერს ინარჩუნებდა, რაც შეიძლებოდა ნომრის დუბლირებით დასრულებულიყო (ინვოისი ვერ ინახებოდა) ან ნომერსა და გამცემს/წელს შორის შეუსაბამობა გამოეწვია;
- ინვოისის ფორმაზე დაემატა შესაბამისი შეხსენება;
- დაემატა ტესტები გამცემის და წლის შეცვლისთვის.

## 1.2.5

უსაფრთხოებისა და სიზუსტის განახლება.

- **ნუმერაცია:** ინვოისის ნომერი ახლა არსებული ინვოისებიდან გამოითვლება (გამცემი + პრეფიქსი + წელი). უკანა თარიღით ინვოისი აღარ არღვევს მიმდინარე წლის ნუმერაციას და აღარ ბლოკავს ახალი ინვოისების შექმნას. უკვე დაზიანებული გამცემები ავტომატურად გასწორდება. შენიშვნა: პრეფიქსის შეცვლისას ახალი პრეფიქსის ნუმერაცია `0001`-დან იწყება;
- **ინსტალერი:** უარს ამბობს მუშაობაზე, თუ ბაზაში უკვე არსებობს მომხმარებლები (დაცვა `storage/config.php`-ის დაკარგვის შემთხვევისთვის);
- **თანხები:** გამოთვლა მთელი რიცხვებით (თეთრებში) ხდება. ინვოისის შეჯამება (ქვეჯამი − ფასდაკლება + დღგ = სულ) ყოველთვის ზუსტად ემთხვევა; ბრაუზერში ცოცხალი ჯამი იგივე ალგორითმს იყენებს. ზედმეტად დიდი რაოდენობა/ფასი უარყოფილია;
- **გაცემული ინვოისი საბოლოოა:** მისი რედაქტირება, მონახაზად დაბრუნება და წაშლა აღარ შეიძლება; შესაძლებელია ნახვა, ბეჭდვა, PDF და ასლის შექმნა. ღილაკი „შენახვა და გახსნა“ გადაერქვა „ინვოისის გაცემა“ და დადასტურებას ითხოვს;
- **პროფილი:** პაროლის ან ელფოსტის შესაცვლელად მიმდინარე პაროლია საჭირო (მცდელობების ლიმიტით). პაროლის შეცვლისას სხვა მოწყობილობებზე გახსნილი სესიები იხურება; ლოგინისას განახლდება CSRF ტოკენი;
- დაემატა `tests/integration.php` (მონაცემთა ბაზის ტესტები) და გაფართოვდა `tests/run.php`.
