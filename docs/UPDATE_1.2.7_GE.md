# განახლება 1.2.7 ვერსიაზე

ეს განახლება ცვლის PHP კოდს, `.htaccess` ფაილებს და დოკუმენტაციას. მონაცემთა ბაზის ცვლილება და ხელახალი ინსტალაცია საჭირო არ არის.

## ნაბიჯები

1. შექმენით მიმდინარე პროექტისა და მონაცემთა ბაზის სარეზერვო ასლი.
2. ახალი ფაილები ატვირთეთ პროექტის ფესვში და ფაილების ჩანაცვლებას დაეთანხმეთ. **დარწმუნდით, რომ ახალი `.htaccess` ფაილებიც აიტვირთა** (პროექტის ფესვში, `public`-სა და `storage`-ში): ზოგი FTP კლიენტი ფარულ ფაილებს ტოვებს.
3. არ წაშალოთ და არ ჩაანაცვლოთ სერვერზე არსებული `storage/config.php`.
4. გახსენით `https://invoice.makhara.ge/version.txt` — პასუხი უნდა იყოს `Makhara Invoice 1.2.7`.
5. გადატვირთეთ PHP-FPM/OPcache და გაასუფთავეთ Cache (FastPanel/Cloudflare/ბრაუზერი).
6. დარწმუნდით, რომ `public/install.php` სერვერზე წაშლილია.

## არასავალდებულო პარამეტრები (`storage/config.php`, `app` სექცია)

- `'trusted_proxies' => [...]` — **Cloudflare-ის უკან მუშაობისას აუცილებელია**, თორემ შესვლის ლიმიტი ყველა ვიზიტორისთვის საერთო იქნება. მზა ბლოკს დაგიბეჭდავთ `php tools/cloudflare-trusted-proxies.php` (იხ. `docs/INSTALLATION_GE.md`, 5.1);
- `'session_idle_minutes' => 120` — უმოქმედობის ვადა წუთებში (0 = გამორთულია).

## რა უნდა იცოდეთ

- ახალი პაროლები უნდა აკმაყოფილებდეს გამკაცრებულ წესს; არსებული პაროლები ძალაში რჩება.
- შეცდომების ჟურნალი ინახება `storage/logs/`-ში. დროდადრო გაასუფთავეთ ძველი ფაილები.
- თუ სერვერი Apache-ს არ იყენებს (მაგ. მხოლოდ nginx), `.htaccess` არ მუშაობს: Document Root `public`-ზე უნდა იყოს მიმართული, ხოლო `storage`, `app`, `database`, `docs` და `tests` nginx-ში უნდა დაიბლოკოს.
