# განახლება 1.2.6 ვერსიაზე

ეს განახლება ცვლის PHP კოდს, ერთ JavaScript ფაილსა და დოკუმენტაციას. მონაცემთა ბაზის ცვლილება და ხელახალი ინსტალაცია საჭირო არ არის.

## ნაბიჯები

1. შექმენით მიმდინარე პროექტისა და მონაცემთა ბაზის სარეზერვო ასლი.
2. ახალი ფაილები ატვირთეთ პროექტის ფესვში (იქ, სადაც `app`, `public`, `storage`, `bootstrap.php` და `VERSION` ჩანს) და ფაილების ჩანაცვლებას დაეთანხმეთ.
3. არ წაშალოთ და არ ჩაანაცვლოთ სერვერზე არსებული `storage/config.php`.
4. გახსენით `https://invoice.makhara.ge/version.txt` — პასუხი უნდა იყოს `Makhara Invoice 1.2.6`.
5. გადატვირთეთ PHP-FPM/OPcache და გაასუფთავეთ Cache (FastPanel/Cloudflare/ბრაუზერი).
6. დარწმუნდით, რომ `public/install.php` სერვერზე წაშლილია.

ეს განახლება მხოლოდ მონახაზის რედაქტირების ნუმერაციას ეხება. თუ 1.2.5-ზე ჯერ არ გადასულხართ, გაიარეთ `docs/UPDATE_1.2.5_GE.md`-ის შენიშვნებიც.
